# 名言コーパス（名言スタイル用ファインチューニング素材）

「名言」スタイルのモデルをファインチューニングするための、歴史上の人物の名言・発言コーパス。

## 収録人物・著作権について

既存の「名言集」をまるごと使うと編集著作物としての著作権に触れる可能性があるため、[Wikiquote日本語版](https://ja.wikiquote.org/)（CC BY-SA）から個々の発言を人物ごとに取得する方式を採用。全員が没後70年以上（2026年時点で1956年以前に没）。

## 出典・抽出方法

各人物のWikiquoteページを[MediaWiki API](https://ja.wikiquote.org/w/api.php)経由でwikitext形式取得し、以下の変換で抽出:
- トップレベルの箇条書き（`* 発言`）のみを対象。`*:`のようなネストした注釈行は除外
- ` -- 出典` 形式の末尾citationを除去
- 行末の`[[...]]`形式のwikilink（多くは出典リンク）を除去
- `(中略）`/`(後略）`以降の省略マーカーで切り詰め
- `[[リンク|表示]]`は表示文字列に、`'''太字'''`等の装飾記法は除去
- 8〜200文字の範囲外（短すぎる/長すぎる）は除外
- `[http://... 表示]`形式の外部リンク（MediaWikiの単一角括弧記法）のみで構成される項目は除外（初回スクレイピング時に2件混入していたのを検出して修正 — 詳細は下記）

各発言の出典（人物ページURL）は`corpus.json`の`url`フィールドに記録済み。

## ファイル

- `corpus.json` — `{person, quote, url}` の配列（出典追跡・クレジット表記用）
- `corpus.txt` — 発言本文のみを連結したプレーンテキスト（学習入力用、発言ごとに空行区切り）
- `finetune.py` — ファインチューニングスクリプト（`ai-tools` conda環境で実行）
- `model-checkpoint/` — 採用したepoch55時点の重み（**gitignore対象**。150MBでGitHubの100MB上限を超えるため、リポジトリには含めない。`finetune.py`＋`corpus.json`から再現可能）

## 規模

151件・合計約4,300トークン。童謡コーパス（[training-data/douyou/](../douyou/)、約6,600トークン）よりさらに小さい。

## ファインチューニング結果（2026-08-04実施）

- 童謡コーパスでの知見を踏まえ、最初から80epochスケジュール（学習率はスケジュール全体の長さに連動して減衰するため）で学習し、epoch45〜80の範囲で生成文を比較して選定。**採用: epoch55**
- 初回スクレイピング後の生成比較で、`[http://... 表示]`形式の外部リンクが2件（松尾芭蕉・上杉鷹山の各1件）コーパスに紛れ込んでいたことが生成文から発覚（URLの断片がそのまま出力に出た）。スクレイパーの`[[...]]`（内部リンク）用の除去処理が`[外部URL 表示]`形式には対応していなかったのが原因。修正して再学習

### わかったこと

- **`model.generate()`の既定動作（EOS到達で停止）で評価すると「文体変化なし」に見えて誤診しかねない**: このコーパスは発言（学習時は各発言+EOSをパディングして学習）が短く、素の`generate()`だとプロンプト直後にほぼ即座にEOSを出して停止してしまう。実際のアプリは`allowEos: false`でEOSを候補から除外して生成するため、**EOSを除外した状態で比較しないと文体変化の有無を正しく判断できない**。除外して比較したところ、松尾芭蕉の句（「旅人と我が名呼ばれん初時雨」「海暮れて鴨の声ほのかに白」）や「とはこの事なり」のような格言調の結びなど、明確な文体変化が確認できた
- **プロンプトによっては学習前のベースモデルの知識が強く残る**: 「友達と」「今日は」プロンプトでは、コーパスには存在しない「更新通知を停止し...最新情報をお届けします」というブログ的な文言がepoch45〜80のほぼ全域で固定的に出た。コーパスがカバーしていない語の文脈では、ファインチューニングの影響が薄くベースモデルの事前学習知識が優勢になる。童謡コーパスの「学校」プロンプトの崩壊と同種の「特定プロンプトの癖」として許容
